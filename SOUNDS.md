# Своя озвучка

Игра синтезирует весь звук сама и без единого файла работает полностью. Но
любой звук из списка ниже можно подменить своей записью — просто положи файл с
нужным именем в папку `public/sounds/`. Файла нет — играет синтез (а у реплик
НПС просто тишина). Ничего в коде править не надо.

## Как назвать файл

```
public/sounds/<имя-слота>.mp3
```

Форматы: `.mp3`, `.ogg` или `.wav` — игра сама найдёт то, что лежит.

Хочешь несколько вариантов одной реплики — добавь их с суффиксом. Игра будет
выбирать случайный, чтобы не приедалось:

```
public/sounds/buravchik_greet.mp3     ← основной
public/sounds/buravchik_greet_2.mp3
public/sounds/buravchik_greet_3.mp3
public/sounds/buravchik_greet_4.mp3   ← максимум четыре
```

После добавления файлов перезагрузи страницу.

## Как записывать

Диктофона в телефоне хватит за глаза. Что важно:

- **Тихая комната.** Выключи вентилятор и кондиционер, закрой окно. Шумок
  фона игра не вычистит, а на общем ветре он будет слышен.
- **Не кричи и держи телефон сантиметрах в двадцати**, чуть сбоку от рта —
  тогда не будет плевков на «п» и «б».
- **Одна реплика — один файл.** Скажи, подожди секунду, останови запись,
  обрежь тишину по краям.
- **Длина:** реплики НПС — 1.5–3 секунды, вскрики и звуки — меньше секунды.
  Всё, что длиннее четырёх секунд, начнёт мешать игре.
- **Громкость выравнивай на слух между файлами.** Игра играет их как есть, в
  один уровень; фон (ветер, листва) специально держится тихо, так что
  перекрикивать его не нужно.
- Реплики персонажей лучше писать одним голосом каждую — Буравчик одним
  человеком, Томер другим, Ави третьим.

Ниже — что конкретно говорить. Это заготовка, а не устав: свои шутки всегда
лучше. Держись только смысла — реплика должна подходить к моменту, в который
она играет, иначе получится каша.

## Буравчик

Мужик в кресле у печки. Спокойный, слегка ворчливый, никуда не торопится.
Говорит негромко, как будто ему лень вставать. По игре он уже произносит
вслух: «Сел я тут, значит, и сижу. А ты ходишь.»

| Файл              | Момент                         |
| ----------------- | ------------------------------ |
| `buravchik_greet` | подошёл и открыл разговор      |
| `buravchik_quest` | выдал задание                  |
| `buravchik_done`  | принял работу и отсчитал деньги|
| `buravchik_light` | ему дали прикурить             |
| `buravchik_no`    | отказал: рано или нечего сдавать |

**`buravchik_greet`** — что говорить:

- «О, живой. Заходи, чего в дверях стоишь.»
- «Ну здравствуй. Опять по лесу шатался?»
- «Слушай, а ты вовремя.»
- «Сел я тут, значит. А ты ходишь.»

**`buravchik_quest`**:

- «Дело есть. Не бесплатно, само собой.»
- «Сходи, принеси. Заплачу, я же не зверь.»
- «Работа простая, справится даже ты.»

**`buravchik_done`**:

- «Ну вот, а говорил — не найдёшь. Держи.»
- «Молодец. Считай, заработал.»
- «Хорошо. Вот твои шекели, не пропей сразу.»

**`buravchik_light`** — ему только что дали прикурить, он благодарен:

- «Вот это по-нашему. Спасибо.»
- «Ох, хорошо. Держи за беспокойство.»
- «Уважаю. Вот тебе за это.»

**`buravchik_no`**:

- «Не сегодня.»
- «Рано ещё. Иди догуляй.»
- «А приносить кто будет, Пушкин?»

## Томер Загур

Хозяин ларька. Бодрый, громче остальных, торгует и не даёт скучать. В игре
он говорит: «Бери, не стесняйся. Улов тоже беру, только не ботинки.»

| Файл          | Момент                     |
| ------------- | -------------------------- |
| `tomer_greet` | открыл торговлю            |
| `tomer_buy`   | продал тебе товар          |
| `tomer_poor`  | у тебя не хватает денег    |
| `tomer_sell`  | принял у тебя улов         |

**`tomer_greet`**:

- «О, покупатель! Заходи, всё свежее.»
- «Ну, чего надо? Всё есть.»
- «Смотри, не стесняйся. Цены как для своих.»

**`tomer_buy`**:

- «Отличный выбор!»
- «Забирай, пользуйся.»
- «Вот это правильно.»

**`tomer_poor`** — с сочувствием, но твёрдо:

- «Денег-то нет, дорогой.»
- «В кредит не работаю.»
- «Приходи с шекелями.»

**`tomer_sell`**:

- «Хорошая рыба. Беру.»
- «Ну вот, а говорил — не клюёт.»
- «Давай сюда. Ботинки в следующий раз оставь себе.»

## Ави Загур

Брат Томера. Только ночью, в капюшоне, говорит **тихо и быстро**, всё время
оглядывается. Это важнее слов: даже нейтральную фразу шёпотом играть страшнее.
В игре он говорит: «Тише. Ты меня не видел, я тебя не видел.»

| Файл        | Момент                       |
| ----------- | ---------------------------- |
| `avi_greet` | ты подошёл к нему в темноте  |
| `avi_deal`  | продал товар или принял вино |
| `avi_job`   | выдал поручение на ночь      |

**`avi_greet`** (шёпотом):

- «Тише ты. Чего надо?»
- «Ты меня не видел. Я тебя тоже.»
- «Быстрее говори, я тут не стою.»

**`avi_deal`**:

- «Держи. И иди уже.»
- «Вот. Только не при брате.»
- «Приятно иметь дело.»

**`avi_job`**:

- «Есть работа. До рассвета, потом не приму.»
- «Сделаешь до утра — заплачу. Не успеешь — твои проблемы.»
- «Только между нами.»

## Употребление

Не реплики, а звуки. Употребление в игре — сценарий на несколько секунд с
вознёй в руках; эти файлы играют в самый его момент, остальное (зажигалка,
шорох, дыхание) игра синтезирует сама. Пишутся близко к микрофону.

| Файл           | Что записать                                                    |
| -------------- | --------------------------------------------------------------- |
| `drug_cocaine` | момент вдоха: резкий короткий втяг носом, потом «кха» и шмыганье. ~1.5 с |
| `drug_hash`    | момент выдоха: длинный выдох и следом настоящий кашель. ~3 с    |
| `drug_heroin`  | момент укола: шипящий вдох сквозь зубы, потом тяжёлое замедляющееся дыхание. ~3 с |

Всё это по игре работает против героя (см. дисклеймер), так что звуки должны
быть скорее неприятные, чем «кайфовые».

## Герой

Это ты сам. Голос один и тот же во всех файлах.

| Файл           | Что записать                                                  |
| -------------- | ------------------------------------------------------------- |
| `hero_puff`    | затяжка: тяга, короткая пауза, выдох. Без слов                |
| `hero_fish`    | «Есть!», «Пошла!», «О-о, какая», «Ну наконец-то»              |
| `hero_hurt`    | короткий вскрик от удара: «Ах!», «Сука!», «Ы-ых». До 0.5 с    |
| `hero_death`   | долгий выдох, хрип, всё стихает. 1–2 с                        |
| `hero_sign`    | у таблички «Круглое озеро»: «Круглое, ага», «Кто это писал вообще», «Ну да, квадратное же» |
| `hero_tribute` | у памятника рыбке: «Спи спокойно, Серёга», «Ты был легендой», «Пират, брат» |
| `hero_butcher` | закончил разделывать: «Ну вот и мясо», «Шкуру не порвал вроде», «Ужин есть» |

`hero_sign` и `hero_tribute` — самые «локальные» слоты, туда и просятся ваши
шутки. Именно их стоит записать в четырёх вариантах.

### Звери

Играют, когда зверь оказался в тридцати метрах от игрока. Громкость игра
подбирает сама по расстоянию, так что записывать надо ровно, без крика.

| Файл           | Что записать                                                   |
| -------------- | -------------------------------------------------------------- |
| `animal_cow`   | протяжное «му-у». 1–1.5 с                                       |
| `animal_boar`  | несколько коротких хрюков подряд. ~1 с                          |
| `animal_deer`  | резкий отрывистый лай косули — короткое «бяк». До 0.5 с        |
| `animal_duck`  | два-три «кря». ~1 с                                             |
| `animal_hare`  | шорох: заяц ломится через траву. Мятая бумага у микрофона сойдёт |

Зомби пиши в нескольких вариантах и разными голосами — стая из двенадцати
одинаковых стонов звучит смешно, а не страшно. И не переигрывай: тихий хрип
в темноте работает лучше, чем крик.
