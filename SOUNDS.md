# Своя озвучка

Игра синтезирует весь звук сама и без единого файла работает полностью. Но
любой звук из списка ниже можно подменить своей записью — просто положи файл с
нужным именем в папку `public/sounds/`. Файла нет — играет синтез (а у реплик
НПС просто тишина). Ничего в коде править не надо.

## Как назвать файл

```
public/sounds/<имя-слота>.mp3
```

Форматы: `.mp3`, `.ogg` или `.wav` — игра сама найдёт то, что лежит.

Хочешь несколько вариантов одной реплики — добавь их с суффиксом. Игра будет
выбирать случайный, чтобы не приедалось:

```
public/sounds/buravchik_greet.mp3     ← основной
public/sounds/buravchik_greet_2.mp3
public/sounds/buravchik_greet_3.mp3
public/sounds/buravchik_greet_4.mp3   ← максимум четыре
```

Длина — сколько нужно, но реплики лучше держать в пределах 2–4 секунд.
После добавления файлов перезагрузи страницу.

## Список слотов

### Буравчик

| Имя файла           | Когда играет                                  |
| ------------------- | --------------------------------------------- |
| `buravchik_greet`   | подошёл и открыл разговор                     |
| `buravchik_quest`   | выдал задание                                 |
| `buravchik_done`    | принял работу и отсчитал шекели               |
| `buravchik_light`   | попросил прикурить                            |
| `buravchik_no`      | отказал (рано, нечего сдавать)                |

### Томер Загур

| Имя файла      | Когда играет                        |
| -------------- | ----------------------------------- |
| `tomer_greet`  | открыл торговлю                     |
| `tomer_buy`    | продал товар                        |
| `tomer_poor`   | у игрока не хватает денег           |
| `tomer_sell`   | принял улов                         |

### Ави Загур

| Имя файла    | Когда играет                        |
| ------------ | ----------------------------------- |
| `avi_greet`  | подошёл к нему ночью                |
| `avi_deal`   | продал товар или принял вино        |
| `avi_job`    | выдал поручение на ночь             |

### Герой

| Имя файла       | Когда играет                                   |
| --------------- | ---------------------------------------------- |
| `hero_puff`     | затяжка                                        |
| `hero_fish`     | вытащил рыбу                                   |
| `hero_hurt`     | получил по морде от зомби                      |
| `hero_death`    | умер                                           |

| `hero_tribute`  | отдал дань уважения Серёге Пирату              |

### Зомби и прочее

| Имя файла        | Когда играет                          |
| ---------------- | ------------------------------------- |
| `zombie_idle`    | бродит поблизости                     |
| `zombie_notice`  | заметил игрока и пошёл на него        |
| `zombie_die`     | упокоен                               |
| `chop`           | удар топором по стволу                |
| `shotgun`        | выстрел из дробовика                  |
| `night_start`    | наступила ночь                        |

Список слотов задаётся в `src/client/audio/slots.ts` — если захочется добавить
новый, дописывать нужно там же.
