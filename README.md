# Круглое озеро

Атмосферная игра от первого лица про лес, воду и сигарету. Озеро в центре карты
квадратное. Табличка на берегу утверждает, что оно круглое. Спорить не с кем.

Работает в браузере на Three.js, весь мир и все звуки генерируются кодом — ни
одной внешней модели, текстуры или аудиофайла.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Сборка в статику: `npm run build` — результат в `dist/`, его можно просто
выложить на любой хостинг. Проверка типов: `npm run typecheck`.

## Управление

| Клавиша    | Действие                             |
| ---------- | ------------------------------------ |
| `WASD`     | идти                                 |
| `Shift`    | бежать, пока хватает дыхания         |
| мышь       | смотреть                             |
| `1`        | закурить, повторно — затянуться      |
| `Esc`      | пауза, вернуть курсор                |

Курение — не украшение. После затяжки на пару секунд теплеет кадр, сужается
обзор, замедляется шаг и глохнут звуки леса. Чем больше выкурено за игровой
день, тем короче дыхание на бегу; к утру всё сбрасывается.

## Что уже есть (этап 1)

- Лес 400×400 м: около трёх тысяч деревьев трёх пород, кусты, камни, трава,
  к краю карты — непроходимая чаща.
- Квадратное озеро 60×60 м с песчаным берегом и табличкой «КРУГЛОЕ ОЗЕРО».
  В воду заходишь по колено, дальше не пускает; шаги по воде звучат иначе.
- Полный цикл суток: рассвет 1 мин, день 8, сумерки 1, ночь 4 — со сменой
  цвета неба, солнца, тумана и звёздами.
- Сигарета: щелчок зажигалки, тлеющий уголёк, затяжки, клубы дыма, окурок.
- Звук целиком синтезируется через WebAudio: ветер, листва, шаги по траве,
  песку и воде, плеск озера, ночные сверчки, дыхание на бегу.

## Как устроен код

Разделение сделано с прицелом на будущий мультиплеер: всё, что должно считаться
одинаково у всех участников, лежит отдельно от отрисовки.

```
src/
  shared/            общее для клиента и будущего сервера
    balance.ts       все игровые числа в одном месте
    rng.ts           детерминированный шум и ГПСЧ
    time.ts          цикл суток, положение солнца
    movement.ts      шаг симуляции игрока и столкновения
    world/
      terrain.ts     высота рельефа как функция от координат
      worldgen.ts    расстановка деревьев и всего прочего по сиду
      grid.ts        поиск препятствий рядом с игроком
  client/            только показ и ввод
    game.ts          сборка сцены и главный цикл
    input.ts         клавиатура и захват мыши
    items/           предметы в руках
    render/          небо, земля, лес, вода, дым, табличка
    audio/           синтез звука
    ui/              HUD и стили
```

Мир не хранится, а вычисляется из сида (`WORLD_SEED` в `balance.ts`): один и тот
же сид даёт один и тот же лес где угодно. Симуляция игрока идёт фиксированным
шагом 1/60 с — сервер потом сможет прогонять тот же `stepPlayer` по присланным
вводам. Баланс правится в `balance.ts`, лезть в остальной код для этого не надо.

В режиме разработки доступны два параметра адреса: `?nolock` — не захватывать
мышь (удобно для скриншотов), `?t=700` — сразу перескочить в нужную секунду
суток.
