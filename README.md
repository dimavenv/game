# Круглое озеро

Атмосферная игра от первого лица про лес, воду и сигарету. Озеро в центре карты
квадратное. Табличка на берегу утверждает, что оно круглое. Спорить не с кем.

Работает в браузере на Three.js, весь мир и все звуки генерируются кодом — ни
одной внешней модели, текстуры или аудиофайла.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Сборка в статику: `npm run build` — результат в `dist/`, его можно просто
выложить на любой хостинг. Проверка типов: `npm run typecheck`.

## Управление

| Клавиша    | Действие                                             |
| ---------- | ---------------------------------------------------- |
| `WASD`     | идти                                                 |
| `Shift`    | бежать, пока хватает дыхания                         |
| мышь       | смотреть                                             |
| `1`        | закурить, повторно — затянуться                      |
| `2`–`6`    | топор, дробовик, удочка, фонарик, молот              |
| `Пробел`   | прыжок (отъедает секунду дыхания)                    |
| `Tab`      | рюкзак                                               |
| `B`        | режим стройки (нужен молот)                          |
| `ЛКМ`      | рубить топором, забрасывать и подсекать удочкой      |
| `E`        | говорить, нарвать яблок, подбросить дров, сесть      |
| `Esc`      | пауза, закрыть разговор                              |

Курение — не украшение. После затяжки на пару секунд теплеет кадр, сужается
обзор, замедляется шаг и глохнут звуки леса. Чем больше выкурено за игровой
день, тем короче дыхание на бегу; к утру всё сбрасывается.

## Что уже есть

- Лес 400×400 м: около трёх тысяч деревьев трёх пород, кусты, камни, трава,
  к краю карты — непроходимая чаща.
- Квадратное озеро 60×60 м с песчаным берегом и табличкой «КРУГЛОЕ ОЗЕРО».
  В воду заходишь по колено, дальше не пускает; шаги по воде звучат иначе.
- Полный цикл суток: рассвет 1 мин, день 8, сумерки 1, ночь 4 — со сменой
  цвета неба, солнца, тумана и звёздами.
- Сигарета: щелчок зажигалки, тлеющий уголёк, затяжки, клубы дыма, окурок.
- Звук целиком синтезируется через WebAudio: ветер, листва, шаги по траве,
  песку и воде, плеск озера, ночные сверчки, дыхание на бегу.
- Поляна у восточного берега: рубленая хижина с печкой и двумя креслами,
  ларёк под навесом, костёр между ними.
- **Буравчик** сидит в кресле: даёт задания за шекели (яблоки или
  толстолобики), принимает работу и берёт прикурить — раз в сутки, за деньги.
- **Томер Загур** торгует из ларька: сигареты, бинты, удочка, фонарик, топор,
  дробовик и патроны; скупает рыбу, яблоки и дрова. Ночью зажигает лампу.
- Рыбалка: заброс по воде, ожидание, поклёвка и щедрое окно подсечки в 2.5 с.
  Карась, окунь, толстолобик и иногда старый ботинок — у каждой рыбы свой вес
  и своя цена.
- Яблони в лесу, рубка деревьев на дрова (пень зарастает за двое суток),
  печка в хижине: горит — в кресле время идёт вчетверо быстрее.
- Памятник рыбке породы петушок в глухом углу леса. Отдать дань уважения можно
  только зажжённой сигаретой и не чаще раза в трое суток — за это сутки клюёт
  заметно лучше.
- Ночью из чащи выходят зомби: бродят, замечают метров с двадцати и идут
  напрямую — медленнее твоего бега, так что убежать можно всегда. Каждая
  следующая ночь на пару тварей больше. На поляну с костром и в хижину они не
  заходят: это единственное безопасное место.
- Бой: топор валит зомби с трёх ударов и отшатывает его, дробовик в упор бьёт
  насмерть (два патрона, долгая перезарядка на `R`). Бинт — `Q`.
- Смерть: экран гаснет, утром приходишь в себя у печки. Минус 30% наличных и
  весь несданный улов; снаряжение остаётся при тебе.
- Прогресс сохраняется в браузер сам. «Начать заново» — в меню по Esc.
- Своя озвучка: положи файл с нужным именем в `public/sounds/` — он подменит
  синтез. Полный список имён в [SOUNDS.md](SOUNDS.md).
- Рюкзак: сетка на 20 ячеек и предел в 45 кг. Перегрузился — идёшь на треть
  медленнее и не бегаешь. Камень весит 2.5 кг, бревно 3, рыба — сколько
  вытянула. Перекладывать можно мышью, а лишнее — в сундук.
- Камни: мелкие подбираются руками, валуны разбиваются молотом за четыре
  удара и дают сразу три камня. И те, и другие возвращаются через двое суток.
- Стройка молотом по готовым чертежам: частокол, ворота, сундук, давильня,
  винный погреб, коптильня, причал и виноградная лоза. Выбираешь колесом мыши,
  перед тобой висит призрак — зелёный значит можно, красный объяснит почему нет.
- Виноделие. По лесу растут дикие лозы, у Томера продаются саженцы — свою лозу
  сажаешь молотом, через двое суток она начинает плодоносить каждый день.
  Грозди топчешь в давильне (четыре грозди — сусло), пять сусла заливаешь в
  бочку погреба и ждёшь: сутки — молодое, трое — выдержанное, семь —
  коллекционное. Разливаешь по бутылкам (нужны пустые) и продаёшь.

## Что дальше

Ави Загур, брат Томера: днём его нигде нет, а ночью он стоит с фонарём где-то
на карте — скупает вино втрое дороже, торгует из-под полы и раздаёт скверные
ночные поручения.

Каркас готов к мультиплееру: мир детерминирован, симуляция идёт фиксированным
шагом, состояние отделено от рендера. Следующий шаг — сервер на Node с
WebSocket, который прогоняет тот же `stepPlayer` и `stepZombies` по присланным
вводам и рассылает состояние.

## Как устроен код

Разделение сделано с прицелом на будущий мультиплеер: всё, что должно считаться
одинаково у всех участников, лежит отдельно от отрисовки.

```
src/
  shared/            общее для клиента и будущего сервера
    balance.ts       все игровые числа в одном месте
    rng.ts           детерминированный шум и ГПСЧ
    time.ts          цикл суток, положение солнца
    movement.ts      шаг симуляции игрока и столкновения
    zombies.ts       поведение стаи и попадания по ней
    quests.ts        задания Буравчика
    fishing.ts       таблица улова
    state.ts         состояние мира и прогресс
    items.ts         реестр вещей: вес, цена, размер стопки
    inventory.ts     сетка рюкзака, вес и перекладывание
    world/building.ts чертежи построек и проверка места
    world/
      terrain.ts     высота рельефа как функция от координат
      worldgen.ts    расстановка деревьев и всего прочего по сиду
      grid.ts        поиск препятствий рядом с игроком
  client/            только показ и ввод
    game.ts          сборка сцены и главный цикл
    input.ts         клавиатура и захват мыши
    items/           предметы в руках
    render/          небо, земля, лес, вода, дым, строения, люди, зомби
    save.ts          сохранение в localStorage
    audio/           синтез звука
    ui/              HUD и стили
```

Мир не хранится, а вычисляется из сида (`WORLD_SEED` в `balance.ts`): один и тот
же сид даёт один и тот же лес где угодно. Симуляция игрока идёт фиксированным
шагом 1/60 с — сервер потом сможет прогонять тот же `stepPlayer` по присланным
вводам. Баланс правится в `balance.ts`, лезть в остальной код для этого не надо.

В режиме разработки доступны два параметра адреса: `?nolock` — не захватывать
мышь (удобно для скриншотов), `?t=700` — сразу перескочить в нужную секунду
суток.
