# Игра вдвоём

Лес один на всех: время суток, срубленные деревья, постройки, стадо и мертвецы
общие. Рюкзак, деньги, здоровье и квесты — у каждого свои.

## Быстро: как поднять на VPS

Нужен только Node 20+ и открытый порт. Ни базы, ни nginx, ни докера.

```bash
git clone https://github.com/dimavenv/game.git
cd game
npm ci
npm run build          # собирает саму игру в dist/
npm run server:build   # собирает сервер в dist-server/
npm run server         # запускает: раздаёт игру и держит сеть на одном порту
```

Открываешь `http://адрес-сервера:8080`, вводишь имя, жмёшь «Играть». Второй
делает то же самое — и вы в одном лесу.

Всё три шага разом:

```bash
npm run serve
```

## Настройки

Задаются переменными окружения:

| Переменная | По умолчанию      | Что делает                                          |
| ---------- | ----------------- | --------------------------------------------------- |
| `PORT`     | `8080`            | порт                                                 |
| `HOST`     | `0.0.0.0`         | адрес, на котором слушать                            |
| `SEED`     | `krugloe-ozero`   | сид мира. **После начала игры не менять** — лес станет другим, а сохранение не подойдёт |
| `SAVE`     | `save/world.json` | файл сохранения мира                                 |
| `PASSWORD` | пусто             | если задан, пускают только по `?pass=…` в адресе     |
| `STATIC`   | `dist`            | откуда раздавать игру                                |

Пример с паролем:

```bash
PORT=8080 PASSWORD=petushok npm run server
# заходить: http://адрес:8080/?pass=petushok
```

## Чтобы не падало при перезагрузке сервера

Простейший systemd-юнит:

```ini
# /etc/systemd/system/ozero.service
[Unit]
Description=Круглое озеро
After=network.target

[Service]
WorkingDirectory=/root/game
ExecStart=/usr/bin/node dist-server/index.js
Environment=PORT=8080
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

```bash
systemctl enable --now ozero
journalctl -u ozero -f     # смотреть, кто зашёл и что говорят в чате
```

Мир сохраняется сам каждые полминуты, при выходе игрока и при остановке
сервиса (`systemctl stop` даёт серверу дописать файл).

## Что видно и что слышно

- **Ники над головами.** Дальше восемнадцати метров рядом с ником пишется
  расстояние — иначе товарища в одинаковом лесу не найти. Дальше двухсот
  двадцати метров подпись гаснет.
- **Чат:** `Enter`, написал, `Enter`. `Esc` — передумал. Сообщения падают в тот
  же угол, что и остальные подсказки, и видны в логе сервера.
- **Фигура** товарища шагает по присланной скорости, приседает, садится в
  кресло и заваливается, когда его убили.

## Кто чем распоряжается

| Что                                        | Где живёт |
| ------------------------------------------ | --------- |
| Время суток и день                         | сервер    |
| Стадо, стая, пещерные                      | сервер    |
| Срубленные деревья, яблони, валуны, камешки, лозы | сервер |
| Постройки и всё, что в них лежит            | сервер    |
| Дрова в печи Буравчика                      | сервер    |
| Рюкзак, деньги, здоровье, голод             | клиент, сервер только хранит |
| Квесты, поручения Ави, найденные пещеры     | клиент, сервер только хранит |
| Своя позиция                                | клиент    |

Позицию и рюкзак сервер не пересчитывает: играем с друзьями, и городить
античит ради двоих — пустая работа. Зато всё, что должно совпадать у обоих
(время, лес, звери), считается в одном месте и разъехаться не может.

Ави никуда не шлётся: его место считается из номера дня и сида, поэтому и так
одинаково у всех. То же и с дроздами в ущелье.

## Про урон

Кабан и мертвецы бьют того, к кому подошли: сервер считает урон отдельно по
каждому и шлёт ровно тому, кому досталось. Ночная стая делится между всеми,
кто в лесу, — вдвоём не становится вдвое страшнее.

Друг друга бить нельзя: топор и дробь по своим не проходят вовсе.

## Одиночная игра никуда не делась

Без сервера (например, `npm run dev`) всё работает по-старому: мир считает сам
клиент, прогресс лежит в браузере. Сеть включается, только когда игра открыта с
сервера или когда в адресе явно указан `?server=ws://адрес:порт`.

## Если что-то пошло не так

- **«Версия игры не совпала с сервером»** — на сервере лежит другая сборка.
  Обнови репозиторий и пересобери обе части (`npm run build && npm run
  server:build`).
- **«Игра не собрана»** вместо страницы — не хватает `dist/`, запусти
  `npm run build`.
- **Связь моргает** — клиент переподключается сам, с нарастающей паузой до
  двенадцати секунд. Прогресс при этом не теряется: он лежит и в браузере, и
  на сервере.
- **Лес у двоих разный** — значит, разные сиды. Сид печатается в логе при
  запуске сервера; сохранение с чужим сидом сервер не читает и предупреждает
  об этом в логе.
