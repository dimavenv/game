# Сюда кладут звуки

Всё, что игра умеет подменять своими файлами, перечислено в `SOUNDS.md` в корне
репозитория. Имя файла — имя слота, расширение любое из `.mp3`, `.ogg`, `.wav`.

Самое частое:

```
public/sounds/avi_music.mp3        ← музыка из колонки Ави, играет по кругу
public/sounds/buravchik_greet.mp3  ← реплика Буравчика
```

Ничего класть не обязательно: чего нет, то игра синтезирует сама (а реплики
НПС просто молчат). После добавления файлов перезагрузи страницу.
