# Фотография в Дантовом ущелье

Положи сюда файл `gorge.png` — он появится в рамке на стене щели, на середине
прохода, слева по ходу от входа. Размер в игре — 42 см, так что хватит любой
картинки от 256×256; лишнего разрешения не нужно.

Прозрачность работает: если вырезать фигуру и сохранить с альфа-каналом,
фон рамки останется тёмной доской.

Пока файла нет, в рамке просто пустая доска — игра от этого не ломается.
